# pi 版本对应关系

本文件是本包与宿主 pi 版本对应关系的单一权威。其余位置，包括 `README.md` 与 `package.json` 的声明键，只作指针或不重复定义。本文件声明的宿主版本范围与 `package.json` 的 `pi.dddSupportedPiVersion` 机读字段必须一致：该字段供机器读取，人读结论以本文件为准；设计册 DESIGN-structure.md 的包清单示例同取一值，三处不得出现第二个版本范围。

本包为 pi package，其扩展、技能、代理与提示模板依赖宿主 pi 的扩展接口。宿主 pi 的接口在不同版本间可能变化，故逐版本记录实测支持情况。表中「已实测的 pi 版本」指该本包版本实际运行过的宿主 pi 版本，非推断区间。

## 声明范围

`package.json` 的 `pi.dddSupportedPiVersion` 声明语义化版本范围，取自上表的实测结论。当前声明的范围为 `>=1.5.0 <1.6.0`，表达本包已实测覆盖的 pi 版本区间，本文件与该机读字段须保持同值。

## 使用者判读

- 若所用 pi 版本落在对应表已列出的范围内，可直接使用。
- 若所用 pi 版本高于表中最高实测版本，或低于最低实测版本，属未实测组合：pi 可能已改变本包依赖的扩展接口，本包亦可能使用了新版新增的能力。
- 会话启动时若探测到宿主 pi 版本落在声明范围之外，本包会在交互界面提示一次，无界面模式写入 stderr；提示仅作提醒，不阻断会话。
- 遇到提示或使用未实测组合时，建议动作依优先次序为：一，升级本包到对应表已覆盖该 pi 版本的较新行；二，将宿主 pi 调整到对应表已实测的版本；三，以未实测组合继续使用，并留意扩展告警与结构治理守卫是否正常。
- 本表随发版更新。新增实测行前不得声明对应组合受支持。
