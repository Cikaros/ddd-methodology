# pi 版本对应关系

本文件是本包与宿主 pi 版本对应关系的**单一权威**。其余位置，包括 `README.md` 与 `package.json` 的声明键，只作指针或不重复定义。

本包为 pi package，其扩展、skill 与子代理依赖宿主 pi 的扩展 API。宿主 pi 的接口在不同版本间可能变化，故逐版本记录实测支持情况。表中「已实测的 pi 版本」指该本包版本实际运行过的宿主 pi 版本，非推断区间。

## 对应表

| 本包版本 | 已实测的 pi 版本 | 实测日期 | 实测方式与结论 |
|---|---|---|---|
| 0.1.0 | 1.4.0 | 2026-11-03 | 以本机安装的 pi 1.4.0 加载本包扩展、skill 与子代理，逐项核对包内实际调用的 pi 扩展 API。结论：所用接口在 1.4.0 全部可用。依据见改造前的 pi 规范探查报告。 |
| 0.1.1 | 1.4.0 | 2026-11-03 | 与 0.1.0 同一宿主 pi 1.4.0，仅改安装文档，未触及扩展 API 面。 |
| 0.1.2 | 1.4.0 | 2026-11-03 | 与 0.1.0 同一宿主 pi 1.4.0，改迁移脚本与安装示例，未触及扩展 API 面。 |
| 0.2.0 | 1.4.0 | 2026-11-03 | 发布期宿主为 pi 1.4.0，扩展共享模块的加载经本机 pi 1.4.0 一次性观测确认。 |
| 0.2.0 | 1.5.0 | 2026-11-04 | 在 pi 1.5.0 下逐项核对本包实际调用的 pi 扩展 API 在 1.4.0 至 1.5.0 之间的语义变化。结论：无一项为确定性破坏，所用接口或不变或为纯新增可选能力。依据见本轮针对 pi 1.5.0 的扩展 API 复核报告。 |

表中未列出的本包版本与 pi 版本组合，或标注为「未记载」者，尚无实测依据，不作支持声明。

## 声明范围

`package.json` 的 `pi.dddSupportedPiVersion` 声明的语义化版本范围，取自上表的实测结论，应保持与上表一致。当前声明与上表一致，表达本包已实测覆盖的 pi 版本区间。

## 使用者判读

- 若所用 pi 版本落在对应表已列出的范围内，可直接使用。
- 若所用 pi 版本高于表中最高实测版本，或低于最低实测版本，属未实测组合：pi 可能已改变本包依赖的扩展 API，本包亦可能使用了新版新增的能力。
- 会话启动时若探测到宿主 pi 版本落在声明范围之外，本包会在交互界面提示一次，无界面模式写入 stderr；提示仅作提醒，不阻断会话。
- 遇到提示或使用未实测组合时，建议动作依优先次序为：一，升级本包到对应表已覆盖该 pi 版本的较新行；二，将宿主 pi 降级到对应表已实测的版本；三，以未实测组合继续使用，并留意扩展告警与结构治理守卫是否正常。
- 本表随发版更新。新增实测行前不得声明对应组合受支持。
