## 范围

### 做

重建对象为方法论本体与工具面，即 skill、agents、scripts、workflows、extensions、global、README。目标为消除本轮盘点确认的四类结构性根因。

1. 消除清单副本。代理名与 skill 名改为单一定义加生成或校验，覆盖此前未受校验的规范角色表、apply-models、workflow 与 profiles。
2. 消除脚本重复。跨脚本同名的文件读取、行号、漂移项构造与目录遍历统一为共享实现。
3. 规范拆分。规范 431 行按其自身的文档粒度阈值重新组织，并纳入度量面。
4. 骨架统一。代理骨架与 frontmatter 声明口径统一，消除四处偏离与规范措辞不符。
5. 校验面补全。裸数字节引用、README 结构树、文档孤儿、计数一致性、版本条目存在性纳入机械校验。
6. 分层收敛。工具与归档占 72% 的重心失衡按重建后的结构重新划分。

### 不做

1. 不改对外契约。skill 名、代理名、阶段键、门禁号、脚本路径与调用形式、CLI 输出契约、安装参数、项目内文件契约一律保持。
2. 不动版本控制历史。docs 归档、CHANGELOG 历史条目的处置须逐项列入废弃清单后方可执行。
3. 不改仓库级约定。换行策略、ASCII 约束、模型配比记录文件的位置保持不变。
