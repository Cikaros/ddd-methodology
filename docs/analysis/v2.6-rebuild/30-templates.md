# 模板契约

对象文件：新增 `skill/ddd-methodology/references/templates-rebuild.md`，并在 `templates.md` 追加一行指针。

## 1. 拆分理由

`templates.md` 现为 162 行，接近文档粒度阈值。本轮新增四个模板约六十行，直接追加将使该文件超过 200 行阈值，触发拆解义务。故新增独立文件承载重建模板，`templates.md` 只留指针。

## 2. templates.md 的改动

在文件末尾追加一节，标题为 `## 存量重建模板`，正文一句：「存量重建与定向重构的产物模板见 `templates-rebuild.md`。」

不得改动 `templates.md` 的其他内容。

## 3. templates-rebuild.md 内容契约

四个模板，节标题固定。

```markdown

- 回溯方法：需要参照旧实现时，从此回溯点读取。
```

### 3.2 ANCHORS 冻结锚点清单

```markdown
# 冻结锚点清单

本清单是重建唯一保留集，范围之外一律可弃。

| 编号 | 类别 | 锚点内容 | 来源 | 继承方式 |
|---|---|---|---|---|

类别取对外契约、仍成立的设计决策、仍被消费的能力三类。

## 范围
做：
不做：

## 用户确认

```

定向重构复用本模板，范围节填写具体模块或问题，锚点可为空但须显式声明为空。

### 3.3 DEPRECATED 废弃清单

```markdown
# 废弃清单

| 编号 | 原路径 | 类别 | 替代物 | 清除时间 |
|---|---|---|---|---|

类别取架构、代码、测试、文档、配置五类。

## 声明

未列入本清单而实际不再使用的产物视为静默保留，属缺陷。
```

定向重构复用本模板，清单可为空但须显式声明为空。

## 4. 与既有模板的关系

1. 四个模板与 `templates.md` 中的既有模板无字段重叠，不构成重复定义。
2. 四个模板的字段须与规范的存量重建节条款对应，逐项可追溯：回溯点记录对应前置检查条，锚点清单对应价值锚点条，废弃清单对应废弃声明与清除条，验证报告对应等价性验证条。
3. 模板中的「类别」取值集合与本契约第 3 节一致，不得另立取值。

## 5. 变更记录要求

`templates-rebuild.md` 为新增，`templates.md` 被触碰。两者均须在 CHANGELOG 登记。
