# 重建与定向重构产物模板

`templates.md` 的配套文件，承载存量重建与定向重构的产物模板。规范条款见 `~/.pi/agent/skills/ddd-methodology/references/spec-rebuild.md` 的「存量重建」节。

```markdown

- 工作区状态：

- 回溯点提交：
- 附加标记：
- 记录时间：
- 回溯方法：需要参照旧实现时，从此回溯点读取。
```

## ANCHORS 冻结锚点清单

```markdown
# 冻结锚点清单

本清单是重建唯一保留集，范围之外一律可弃。

| 编号 | 类别 | 锚点内容 | 来源 | 继承方式 |
|---|---|---|---|---|

类别取对外契约、仍成立的设计决策、仍被消费的能力三类。

## 范围
做：
不做：

## 用户确认
- 确认时间：
- 确认结论：
```

定向重构复用本模板，范围节填写具体模块或问题，锚点可为空但须显式声明为空。

## DEPRECATED 废弃清单

```markdown
# 废弃清单

| 编号 | 原路径 | 类别 | 替代物 | 清除时间 |
|---|---|---|---|---|

类别取架构、代码、测试、文档、配置五类。

## 声明

未列入本清单而实际不再使用的产物视为静默保留，属缺陷。
```

定向重构复用本模板，清单可为空但须显式声明为空。

|---|---|---|---|---|

|---|---|---|

- 变更后用例数：
