# 项目根文件模板

本文件承载项目级指令文件与术语表两个项目根文件的模板，其余产物模板见 `templates.md`。

## AGENTS.md

置于项目根，由架构设计期产出初版，迭代收尾核验更新；维护责任、触发与判据见「项目级指令文件的维护」节。

```markdown
# 项目级指令

## 项目定位与技术栈
本项目做什么，语言与运行时、框架、构建与测试工具及版本。

## 目录结构与依赖方向
目录树，每目录一句话职责，并标注依赖方向。

## 项目约定
本项目特有约定与禁忌，逐条带判据。

## 方法论要点
本项目实际使用的方法论要点，含门禁与产物路径、机械校验入口与证据产出方、模型配比与解析器启停入口，以及判定对象不存在时的「不适用」写法。

## 已知债务
已知债务与遗留，含接受理由或承接去向。
```

内容边界、维护责任与判据见「项目级指令文件的维护」节，本文不重述。

## GLOSSARY.md

置于项目根，本项目术语的唯一权威处；字段与必填项见规范「表述与术语」节。

```markdown
# 术语表

| 术语 | 类别 | 指什么 | 不指什么 | 落地锚点 | 白话解释 |
```

超过文档粒度阈值时按领域拆分到 `docs/glossary/`，主文件只留索引。
