# 缺陷四级路由（代理自包含知识切片）

> 本文件为派发给子代理的知识附件（经 agent frontmatter skills: 自动加载），与 references/defect-routing.md 同源同步；修改路由规则必须双改（权威源：references/defect-routing.md）。

## 四级定义与处理
| 级别 | 定义 | 处理 |
|---|---|---|
| A 需求级 | 设计无法满足需求，或需求矛盾/缺口 | 回代理1→必须升级用户确认 |
| B 设计级 | 设计缺陷、边界不清、接口矛盾、冻结接口不可实现 | 代理2/3 修订设计+同步修订 AC |
| C 实现级 | 设计正确但实现偏离 | ddd-fixer 修码，不改设计 |
| D 测试级 | 计划漏场景/错断言/覆盖缺口 | ddd-fixer 修计划，重跑 |

## 判定流程
严格按序自检，默认最低层。
1. D：复核测试计划——漏场景/断言错/覆盖缺口？
2. C：比对代码与就近 DESIGN.md——实现偏离设计？
3. B：设计自洽性——矛盾/边界不清/接口不可实现？
4. A：设计正确执行后仍不满足总 AC？
低层自检通过仍失败才上移一层。仅 B 级及以上回设计层。

## 终止与仲裁
- 同一缺陷轮回修复超过 2 轮 → 强制停止升级用户。
- 定级争议 → 根会话仲裁（必要时派 ddd-arbiter）。
