# FastAPI

## 使用边界

此 Skill 是 **DDD 文档/验收流程中的技术参考**，不是新的门禁；项目明确的配置、框架版本和冻结设计优先。先检查仓库文件和锁文件，再选择命令。未验证的工具结果不得当成通过。若任务与本技术无关，不加载。

## 实施约束

1. 端点输入输出使用 Pydantic Schema，不把内部实体直接暴露。
2. 同步阻塞代码不要放在 async 路径中。
3. 依赖注入提供数据库会话、权限、配置等边界。

## 常见反例

- 异步端点调用阻塞客户端
- 422/验证异常未分类并缺测试

## 可执行验证（先检测是否安装及配置）

- `pytest`
- `python -m compileall .（按项目范围）`

不要在没有依赖、配置或授权时假定命令成功；失败时保存 stderr、退出码和关联源码版本供 G5/G6 核验。
