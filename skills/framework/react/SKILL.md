# React 组件

## 使用边界

此 Skill 是 **DDD 文档/验收流程中的技术参考**，不是新的门禁；项目明确的配置、框架版本和冻结设计优先。先检查仓库文件和锁文件，再选择命令。未验证的工具结果不得当成通过。若任务与本技术无关，不加载。

## 实施约束

1. 组件负责渲染，副作用仅在合适的 Hook 生命周期执行。
2. 状态最小化，派生数据避免重复持有。
3. 键稳定、语义标签和键盘可访问性优先。

## 常见反例

- useEffect 依赖缺失或造成循环
- 列表键不稳定与服务端 hydration 不一致

## 可执行验证（先检测是否安装及配置）

- `npm test（按项目配置）`
- `npm run build（如存在）`

不要在没有依赖、配置或授权时假定命令成功；失败时保存 stderr、退出码和关联源码版本供 G5/G6 核验。
