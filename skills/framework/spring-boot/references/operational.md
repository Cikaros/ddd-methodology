# Spring Boot · 操作参考

## 发现与选择

项目已有的 `README`、配置文件和锁文件优先于默认值。命令执行前先确认当前工作目录、目标环境及权限；输出仅作为验证证据，不自动替代 DDD 的设计/测试树。

## 实施检查

1. Controller/Service/Repository 分层明确，DTO 与持久层实体分离。
2. 事务范围及回滚规则显式定义，避免长事务。
3. 配置以环境隔离，敏感值不提交；验证鉴权和数据边界。

## 排错优先级

- 自调用导致 @Transactional 未生效
- JPA N+1、懒加载和分页问题

1. 检查该项目使用的版本、包管理器和项目级脚本。
2. 最小化复现并记录退出码、关键错误和输入版本。
3. 改动对应的设计与测试，确认现象消失，必要时增加回归用例。
