# 契约规范

## 何时用

- decomposer 节点，撰写目录级 DESIGN.md 与签名级契约。
- detail-design 节点，撰写文件级 DESIGN-源文件名.md。
- interface-review 节点，评审契约与冻结。
- 涉及接口冻结或变更判定时。

## 做什么

**两级契约分工。** 语义只在一处定义。

| 级 | 承载 | 不承载 |
|---|---|---|
| 目录级 | 跨模块接口的语义契约，即接口名、签名、参数、返回、错误语义、时序依赖与副作用、消费方模块、调用示例 | 文件内部实现细节 |
| 文件级 | 该文件导出面的清单与实现约束，含导出符号、可见性、依赖方向、对应义务条目 | 语义重复，不重抄目录级契约 |

**目录级契约表**（列头固定，被机械校验锚定，不得改写）：

| 接口名 | 签名 | 参数 | 返回 | 错误语义 | 时序依赖与副作用 | 消费方模块 | 调用示例 |
|---|---|---|---|---|---|---|---|

- 契约表置于文档前部；无消费方的接口不得写入；时序依赖未标注即视为顺序无关。
- 文件级对目录级条目只引用不重写，重写即判缺陷。
- 可观测性契约随契约冻结：按关键路径列出日志标识、trace 上下文传播、metric 名称与单位、失败可观测性四项中适用者，不适用项写「不适用」并给理由，不留空。

**文件级五节**（顺序固定，标题不得改写）：

| 节 | 内容 |
|---|---|
| 目标 | 该文件存在的目的与能力边界，含不包含什么 |
| 重点功能实现思路 | 关键路径的设计意图与选型理由，不写逐行实现 |
| 对外接口清单 | 该文件导出的符号与其可见性 |
| 依赖接口清单 | 该文件引用的外部符号及其来源 |
| 被依赖清单 | 引用该文件导出面的其他文件与其符号 |

**覆盖判据。** 有对外导出的文件必写文件级设计；无导出但高风险或高复杂者（由行数与义务条目数判定）可单列；无导出的普通内部文件不写。

**DESIGN.md 结构**（节名固定）：摘要（三行以内）、职责描述、能力范围（做／不做）、对外接口与约定、实现文件粒度预判、依赖约束、模块级验收要点、子场景索引、变更记录。

**实现文件粒度预判**（表头固定）：`实现文件 | 职责边界 | 是否基础能力`。拆解阈值以 spec 粒度节为唯一权威。

**模块级验收要点**（表头固定）：`模块级 AC | 覆盖的总 AC | 判定条件`。

**冻结规则。** 接口在分解设计期写成签名级契约并冻结。冻结锚点记冻结时刻的 git commit 引用，写入 `docs/design/FREEZE.json`；契约指纹已废弃，变更判定改为对「对外接口与约定」节做范围限定 diff，diff 非空即行为变更、须同步 AC。节区间按目录级「对外接口与约定」标题定位至下一同级标题，不得与非接口段落混淆。

**实现义务清单与核销。** 可执行义务逐条编号并成为可核销对象，编号由来源派生，不按顺序分配。

| 来源 | 编号形态 | 生成方式 | 覆盖范围取值 |
|---|---|---|---|
| 契约表接口行 | `OB-IF-<接口名>` | 抽取生成 | 该行消费方模块列，或粒度预判表中对应实现文件 |
| 契约表错误语义与副作用列 | 随接口行合并为一条 | 抽取生成 | 同接口行 |
| 可观测性契约声明 | `OB-OBS` | 抽取生成 | 关键路径文件，多文件时写目录前缀 |
| 粒度预判表行 | `OB-FILE-<实现文件相对路径>` | 抽取生成 | 该实现文件路径 |
| 模块级验收要点表行 | `OB-AC-<模块级 AC 编号>` | 抽取生成 | 该模块 |
| 横切规范编号行 | `OB-C-<规范编号>` | 人工登记 | 各受影响模块各登记一条引用行 |
| 就近 DESIGN 追加语义条目 | `OB-X-<短名>` | 人工登记 | 该条目所在模块 |

- 覆盖范围只写路径形态即相对路径或目录前缀（以斜杠结尾），不写逻辑模块名；判定取精确等值或目录前缀二式。
- 节点三组取值：类型取里程碑、模块、义务、执行；确定度取待定、已确定；状态取未开始、进行中、已核销、不适用、已废弃。该三组为唯一权威。
- 核销载体为任务树根索引与模块节点文件两处；义务节点只存引用与状态，不复制义务语义。
- 核销断言四项：抽取生成类义务在对应模块节点文件都有节点；节点表合法（编号唯一、父节点合法、取值合法、已核销者证据指针非空、不适用者理由非空、已废弃者登记信息非空、覆盖范围可在就近 DESIGN 解析到）；未开始与进行中的义务节点须有债务编号或具名承接方；已收口里程碑名下节点须为已核销、不适用或已废弃，已核销节点在相邻两轮快照中不得改写或删除。

## 不做什么

- 不写文件内部实现细节与逐行实现。
- 无消费方的接口不得写入契约，不引入「将来可能用到」的预留声明。
- 文件级不重抄目录级契约语义，重写即判缺陷。
- 无导出的普通内部文件不写文件级设计。
- 覆盖范围填逻辑模块名者不参与覆盖判定，该文件按未被覆盖处理。
