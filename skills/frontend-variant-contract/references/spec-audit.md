# 变体审计（spec-audit）

## 定位

变体审计＝**项目登记门禁**（按对接规范七字段登记），**非** ddd 内置 G1–G6。

## 两类失败（各自独立 remedy）

| 类别 | 例子 | remedy |
|---|---|---|
| **token 值违规** | 硬编码颜色/间距、组件内写死视觉值 | 改用语义 token；变体切换只在应用 shell 层 |
| **变体契约违规** | 使用了契约枚举外的值、未声明组合 | 只在 `docs/variant-contract.json` 封闭枚举内取值；越界须先扩契约并附代价 |

## 门禁自省（R28 七字段）

须自报：`id` / 判面 / 执行者 / 读数形态 / 完成判据 / 失败语义 / 是否入节点源；另留 `ext`。
**「零违规」与「无判定对象」是两个读数**。

## 派生物

`theme-config` 与契约**重放一致**；不一致即失败（禁手改）。
