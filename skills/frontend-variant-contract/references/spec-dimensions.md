# 维度（spec-dimensions）

## 五维标准枚举

| 维 | 说明 | 典型枚举 |
|---|---|---|
| 主题模式 | 明/暗（可含高对比） | `light` / `dark` / `high-contrast` |
| 品牌租户 | 多租户品牌 | 有限租户清单 |
| 密度 | 信息密度 | `comfortable` / `compact` |
| 强调色 | 主色变体 | ≤2 个有限枚举 |
| 圆角风格 | 圆角尺度 | ≤2 个有限枚举 |

## 判据

- 每维须是**封闭枚举**而非开放区间。
- **默认建议（非硬法则）**：总维度 ≤3；强调色、圆角各 ≤2。**超限须附代价说明**，可改（Build to Delete）。
- 「**30 秒说不出场景即封死**」：说不出该维服务于什么真实场景，即不应纳入。

> 字段结构以 `assets/variant-contract-schema.json` 为准。
