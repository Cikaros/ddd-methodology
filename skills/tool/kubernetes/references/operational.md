# Kubernetes 清单 · 操作参考

## 发现与选择

项目已有的 `README`、配置文件和锁文件优先于默认值。命令执行前先确认当前工作目录、目标环境及权限；输出仅作为验证证据，不自动替代 DDD 的设计/测试树。

## 实施检查

1. 明确 namespace、资源请求/限制、探针及滚动发布。
2. 密钥从 Secret/外部密钥系统注入，不存明文。
3. 生产变更先 dry-run/diff，再执行，留回滚路径。

## 排错优先级

- 默认命名空间误操作
- 将 readiness 与 liveness 混为一谈

1. 检查该项目使用的版本、包管理器和项目级脚本。
2. 最小化复现并记录退出码、关键错误和输入版本。
3. 改动对应的设计与测试，确认现象消失，必要时增加回归用例。
