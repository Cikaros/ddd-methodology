# Playwright E2E · 操作参考

## 发现与选择

项目已有的 `README`、配置文件和锁文件优先于默认值。命令执行前先确认当前工作目录、目标环境及权限；输出仅作为验证证据，不自动替代 DDD 的设计/测试树。

## 实施检查

1. 以 role/label/testid 做稳定 locator，避免依赖脆弱 DOM 层级。
2. 隔离测试数据并明确清理策略。
3. 失败保存 trace/screenshot 以便复现。

## 排错优先级

- 使用硬 sleep 代替等待可观察状态
- 测试并行共享账号造成冲突

1. 检查该项目使用的版本、包管理器和项目级脚本。
2. 最小化复现并记录退出码、关键错误和输入版本。
3. 改动对应的设计与测试，确认现象消失，必要时增加回归用例。
