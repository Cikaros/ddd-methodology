# Vite 开发

## 使用边界

此 Skill 是 **DDD 文档/验收流程中的技术参考**，不是新的门禁；项目明确的配置、框架版本和冻结设计优先。先检查仓库文件和锁文件，再选择命令。未验证的工具结果不得当成通过。若任务与本技术无关，不加载。

## 实施约束

1. 明确 dev/build/preview 脚本及环境差异。
2. VITE_ 前缀变量可能暴露到客户端，不得存密钥。
3. 模块/静态资源路径与部署 base 配置一致。

## 常见反例

- 构建产物中泄露 secrets
- 混淆开发服务器代理与生产代理

## 可执行验证（先检测是否安装及配置）

- `npm run build（脚本存在时）`
- `npm run preview（按需）`

不要在没有依赖、配置或授权时假定命令成功；失败时保存 stderr、退出码和关联源码版本供 G5/G6 核验。
