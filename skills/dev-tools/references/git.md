# git 使用约定

## 提交

- 一个逻辑变更一个提交；信息含三要素（为什么做/本次不做/怎么算做对）。
- 不提交生成物、依赖、临时件；`docs/temp.jsonl` 逐条登记临时件。

## 分支

- 特性分支短生命周期；合并前先 rebase 到目标分支最新。
- 冻结点即 git 检查点（R63）：需求/概要/设计树/代码冻结各一次本地提交，提交后工作区干净。

## 历史改写

- `git rebase`/`amend`/`push --force` 仅限**未推送**的本地分支。
- 已推送分支的历史改写属破坏性动作，走守卫层；形态交宿主 shell 扫描器。

## 纪律

- 变更流 `docs/CHANGELOG.jsonl` 只经唯一工具写入、禁手改（权限 `deny`）。
