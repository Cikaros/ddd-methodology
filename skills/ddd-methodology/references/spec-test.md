# 测试规范（spec-test）

## 用例合格形态

- 每条用例含**编号 / 名称 / 期望 / 落地**四列。
- 期望须是**可判定**的；期望值须有**人工校对面**（不能只由被测者自证）。

## 编号唯一

- 编号**全局唯一**（`UT-` 文件级、`GT-` 分组级、`MT-` 模块级、`ST-` 子项目级）。
- 被声明即有执行面：声明的编号须在测试语料里出现过。

## 落地凭据

- 未落地报「**待落地**」而非「缺陷」——两者是不同读数。
- 四级测试：文件级 → 分组级 → 模块级 → 子项目级；有问题退回实现层迭代。
- 三种验证手段并存：① 无模型自测（离线可跑）② 类型检查 ③ 真跑（端到端需模型）。

> 编号规则与落地判据的编号见概要设计与用例清单，本件只写语义。
