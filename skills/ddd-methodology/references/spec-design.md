# 设计规范（spec-design）

## 四级同构

- 子项目／模块／分组／文件四级，与仓库目录逐层一一对应：`docs/ddd/<X>` ↔ 根 `<X>`。
- 文件级设计件四必备节：**定位与边界 / 对外暴露接口 / 需引入的依赖 / 调用的模块能力及接口**。

## frontmatter 用法

- `doc` / `level` / `target` / `status` / `landed` / `covers` / `depends` / `updated`。
- `status` 分 `draft`／`frozen`；**`landed: true` 只允许出现在 `frozen` 件上**。
- `depends` 指**所依赖设计件的 `target`**（计划代码/资产路径），不是设计文档路径。

## 对账语义（四条同族判据）

1. 声明了但实物没有；
2. 实物导出了但设计一字未提；
3. 源件无落点；
4. 引用面不可解析。

四类对账零失败方过 G3。

## 冻结即归并

- 设计冻结时剔正文内联痕迹；把多轮补丁合并为终稿；契约表述**逐字**对齐实物。
- **「凭空发明」是最重缺陷**：签名须与实物逐字对账。
