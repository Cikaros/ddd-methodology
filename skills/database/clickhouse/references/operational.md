# ClickHouse MergeTree · 操作参考

## 发现与选择

项目已有的 `README`、配置文件和锁文件优先于默认值。命令执行前先确认当前工作目录、目标环境及权限；输出仅作为验证证据，不自动替代 DDD 的设计/测试树。

## 实施检查

1. 先确认 local/Distributed 表、分片和复制拓扑再执行变更。
2. 写入与分区设计遵循 MergeTree 排序键和分区裁剪。
3. 大批量迁移分批校验数量、校验和及重复插入策略。

## 排错优先级

- ON CLUSTER 权限不足时擅自推断所有节点一致
- TRUNCATE/DROP 等破坏性操作未经确认

1. 检查该项目使用的版本、包管理器和项目级脚本。
2. 最小化复现并记录退出码、关键错误和输入版本。
3. 改动对应的设计与测试，确认现象消失，必要时增加回归用例。
