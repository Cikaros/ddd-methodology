# MongoDB 文档建模 · 操作参考

## 发现与选择

项目已有的 `README`、配置文件和锁文件优先于默认值。命令执行前先确认当前工作目录、目标环境及权限；输出仅作为验证证据，不自动替代 DDD 的设计/测试树。

## 实施检查

1. 按读写访问路径决定嵌入还是引用。
2. 更新操作带过滤条件并检查 matchedCount/modifiedCount。
3. 对集合索引、聚合管线和 schema 校验设置可观测验证。

## 排错优先级

- 无过滤 updateMany/deleteMany
- 跨文档事务滥用或缺索引

1. 检查该项目使用的版本、包管理器和项目级脚本。
2. 最小化复现并记录退出码、关键错误和输入版本。
3. 改动对应的设计与测试，确认现象消失，必要时增加回归用例。
