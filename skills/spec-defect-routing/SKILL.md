# 缺陷路由规范

## 何时用

- test-execute 节点，给测试失败项定级并路由。
- defect-fix 节点，按路由单修复并计数轮回。
- 出现定级争议时，供仲裁引用条款。

## 做什么

**四级定级表。** 命中即停；未命中任一级特征时取最低适用级别。

| 级别 | 定义 | 去向 | 是否经用户 |
|---|---|---|---|
| D 测试级 | 计划漏场景、断言错或覆盖缺口 | 缺陷修复者改 TEST.md | 否 |
| C 实现级 | 实现偏离设计 | 缺陷修复者改代码，不改设计 | 否 |
| B 设计级 | 设计矛盾、边界不清、接口不可实现 | 回设计分解者并同步 AC | 否 |
| A 需求级 | 设计正确执行仍不满足总 AC | 回需求采集者，须经用户确认 | 是 |

**自检顺序。** 按 D、C、B、A 固定顺序自问，命中即停，取该级处理动作；只有 B 级及以上回设计层。

**轮回与仲裁。** 同一缺陷轮回修复超过两轮仍未解决，强制升级用户；仲裁计入轮回。仲裁并入根会话，不外包独立代理，三条约束：

- 裁决须引用具体规范条款与被批驳主张，不得只给结论。
- 两轮上限不变，根会话不得自行突破。
- 裁决记录写入缺陷路由单的裁决节，供下一轮排除。

## 不做什么

- 不自造第五级，不合并或重排四级。
- 未命中任一级特征时不得默认升级，取最低适用级别。
- A 级不经用户确认不得改需求。
- 仲裁不外派独立代理。
