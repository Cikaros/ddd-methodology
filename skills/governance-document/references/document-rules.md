# 文档粒度与结构治理细则

本文件是 governance-document 技能的长条款补充，不重复技能正文的阈值与判据。

## 一 拆分的两种形态

1. 分类文件：按同构场景分类，父级只留共性契约与拆解说明。
2. 子场景子目录：同构场景达到阈值时按子场景建目录，各子目录一份设计文档。
3. 两种形态的父级一律不重复子场景细节；子场景索引按模板给出子场景、文档路径、一句话职责与场景级 AC 四列。

## 二 结构约束与模板的分工

| 事项 | 落点 |
|---|---|
| 骨架与字段填法 | `../../ddd-methodology/references/templates.md` 与同目录各 `templates-*.md` |
| 篇幅与契约数阈值、接近上限引用 | 本技能正文 |
| 摘要三行、锚定章节名、机读行不得缺行 | 本技能正文 |
| 文档内容的语义正确性 | 接口评审与交叉检查 |
| 度量字段名与阈值承载体 | `../../ddd-methodology/references/spec-declare.md` 第十四节与 governance-code |
| 文档写入者的结构治理回执字段 | governance-code |

本技能只定约束，骨架与填法一律留在模板，两处不得各写一份。

## 三 与其他技能的分界

1. 与 governance-code：代码阈值与接近上限口径归后者，本技能只引用其口径。
2. 与 governance-declaration：模板字段是否被消费属声明面判据，归后者。
3. 与 governance-comment：注释与死代码判据归后者。
4. 与主技能：门禁表、节点序列与状态文件 schema 归主技能，本技能只引用 G4 与 G6 中涉及文档的判据。

## 四 拆解后的核验

1. 拆分后父级与子级同受文档阈值管辖，父级不因拆分而脱离度量。
2. 父级出现重复子场景细节即判漂移，属文档同步者的巡检面。
3. 拆分不改变文档树覆盖全部实现目录这一门禁判据，也不改变模块级 AC 之和覆盖总 AC 的断言。
4. 阈值仅报告不阻断，阻断地位由 G6 的门禁条件承接；恶化项须逐项给出接受理由或定级改造。
