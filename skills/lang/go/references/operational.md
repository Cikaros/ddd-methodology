# Go 模块 · 操作参考

## 发现与选择

项目已有的 `README`、配置文件和锁文件优先于默认值。命令执行前先确认当前工作目录、目标环境及权限；输出仅作为验证证据，不自动替代 DDD 的设计/测试树。

## 实施检查

1. error 逐层传播并保留上下文；不忽略返回值。
2. goroutine 必须有取消、超时和退出策略；共享状态用明确同步。
3. ctx 在 RPC/数据库调用中传递，使用 defer 及时释放资源。

## 排错优先级

- nil interface 与 nil pointer 混淆
- goroutine 泄漏、竞态访问

1. 检查该项目使用的版本、包管理器和项目级脚本。
2. 最小化复现并记录退出码、关键错误和输入版本。
3. 改动对应的设计与测试，确认现象消失，必要时增加回归用例。
