# C# / .NET 异步 · 操作参考

## 发现与选择

项目已有的 `README`、配置文件和锁文件优先于默认值。命令执行前先确认当前工作目录、目标环境及权限；输出仅作为验证证据，不自动替代 DDD 的设计/测试树。

## 实施检查

1. 启用 nullable reference types 并处理 null 警告。
2. I/O 异步 API 正确传播 CancellationToken。
3. 依赖注入边界清晰，避免静态共享可变状态。

## 排错优先级

- async void 无法观测异常
- ORM N+1 查询与同步阻塞

1. 检查该项目使用的版本、包管理器和项目级脚本。
2. 最小化复现并记录退出码、关键错误和输入版本。
3. 改动对应的设计与测试，确认现象消失，必要时增加回归用例。
