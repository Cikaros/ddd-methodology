# Rust 所有权 · 操作参考

## 发现与选择

项目已有的 `README`、配置文件和锁文件优先于默认值。命令执行前先确认当前工作目录、目标环境及权限；输出仅作为验证证据，不自动替代 DDD 的设计/测试树。

## 实施检查

1. 公开 API 优先 Result/Option，不用 unwrap/expect 掩盖可恢复错误。
2. 所有权与生命周期优先简化数据流，避免不必要的 clone。
3. unsafe 必须限定范围并说明不变量。

## 排错优先级

- 错误链丢失
- 异步生命周期或 Send/Sync 约束未满足

1. 检查该项目使用的版本、包管理器和项目级脚本。
2. 最小化复现并记录退出码、关键错误和输入版本。
3. 改动对应的设计与测试，确认现象消失，必要时增加回归用例。
